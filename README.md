# DSA Visualizer

Interactive web application for learning data structures through visual, step-by-step execution.

## Current features
- Array, Stack, Queue and Linked List visualizations
- Insert, delete and search operations
- Step-by-step execution controls
- Time-complexity panel
- Responsive dark UI
- Built with Next.js, React and TypeScript

## Roadmap
- Binary Search Tree
- Heap and priority queue
- Hash table collision visualization
- Graph editor
- BFS, DFS and Dijkstra animations
- Sorting algorithm visualizations
- Code execution panel with highlighted current line
- Saved visualizations and progress tracking

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deployment
This project is designed for Vercel deployment. Connect the GitHub repository to Vercel and use the default Next.js build settings.
